# 零经验试读记录（§9.3 第 12 条）

状态：**未完成——这一条必须由人来做，xdev 实现阶段无法代替。**

## 为什么不能由实现阶段代做

§9.3 第 12 条要验证的是"一个没进过健身房的人读完之后能不能独立说出该做什么"。
这条检验的对象是<b>读者的理解</b>，不是文本的结构——而实现阶段能检验的只有后者。
由写这份教程的一方自己回答"读得懂吗"，得到的答案没有信息量，所以这里不填一个假的"已通过"。

## 执行方法（照此做即可）

1. 找至少 1 位<b>无健身房经验</b>的读者（不要找已经在练的人）。
2. 请他读：第 0 章导读、第 1 章、第 2 章，以及参考库里的 3 张动作卡
   （建议 `#ex-back-squat-high-bar`、`#ex-db-bench-press`、`#ex-push-up`——
   一张有保护前置条件的、一张它的替代动作、一张纯自重的）。
3. 读完后<b>合上页面</b>，请他回答三个问题，并逐字记录他的原话：
   - 你第一次训练打算做哪几个动作？
   - 第一个动作用多重？这个重量怎么定出来的？
   - 做不动了怎么办？
4. 对每个他卡住、答错、或需要翻回去找的环节，在下表登记为缺陷，并指明要修订的章节／动作卡。

## 验收判据

三个问题他都能<b>不翻页</b>答出来，且第 2、3 题的答案是具体流程（"空杆 8 次 → 加到还剩 2 次 → 取 90%"、
"往保护杆上坐"）而不是含糊的"用轻一点的重量""小心一点"，才算通过。
任何一条答不上来，都记为缺陷并修订对应章节，而不是记为"读者没认真读"。
